# RobertChat - README

## Description
-	This is my Python learning project.
-	It is a simple
	"looking-forward-to-being-a-chatbot".
-	To test it,
	just download the version folder
	and unpack it at your desired target.
-	The source files are available,
	to see its development progress.

## Starting the current version 'RobertChat'
Just start the `robertchat.exe` by:
-	double-clicking the application file
-	or selecting the application file and hitting `[ENTER]`

No Python installation is required for the ready-to-use EXE.

## Testing older versions of 'RobertChat'
To test older versions of 'RobertChat' you need:
-	Python (version 3.14.7 or higher)
-	pip (version 26.2.1 or higher)
-	PyInstaller (version 6.22.3 or higher)
-	Previous versions are not recommended.

## Compiling older versions of 'RobertChat'
-	Every version contains its own
	`robertchat.cmd` file.
-	To compile the current version,
	start `robertchat.cmd`.
	<br>It will compile the Python source code to `robertchat.exe`.
-	Some experience with Python may be required.

## Test versions and versions previous to 0.3
-	Test versions that may have a version number like `0.7a`
	are not included in the repository.
-	Versions 0.0 up to 0.2 ran under the generic name `PyChatBot`,
	but they are basically the same application project.
